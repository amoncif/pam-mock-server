# Client collections

Both collections are generated by `php bin/generate.php` from the project OpenAPI operations and fixture scenario definitions. Do not edit generated requests directly.

Postman: import the collection and environment from `postman/`, select **PAM Mock local**, then run **Authentication**. Each login captures the token, uses it on the project-only diagnostic route, then logs off. The last request expects a 403 invalid-credentials response.

Bruno: open the `bruno/` folder, select **local**, and run the **Authentication** folder. The same sequence and assertions apply.

Base URL is `http://localhost:8080`. The common variables are `baseUrl`, `username`, `password`, and `token`. Other provider credentials and `samlResponse` are explicitly fictional environment values. Future domain folders are intentionally empty; their operations are visible as stubs in Swagger.
